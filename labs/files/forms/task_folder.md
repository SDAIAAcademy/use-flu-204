# ملف مهمة الوكيل المتعقَّبة

المهمة في سطر: ……  المواد: اصطناعية / مجهولة الهوية

1. `brief.txt`: الموجز ببنوده السبعة.
2. `permissions.md`: جدول الصلاحيات والموافقات، وسبب كل صلاحية.
3. `run1_log` و`run2_log`: سجلا التشغيلين بطوابعهما الزمنية، وسجل الموافقات.
4. `review_run1.md` و`review_run2.md`: قائمة المراجعة لكل تشغيل، والمراجعة الأولى دون مساعد ذكي.
5. `decision.md`: ما تغيّر بين التشغيلين ولماذا، والقرار: إبقاء أو تعديل أو إيقاف.

شرط لا استثناء فيه: لا إجراء لا رجعة فيه بلا موافقة في أي من السجلين.
