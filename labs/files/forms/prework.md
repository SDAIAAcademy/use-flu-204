# العمل التحضيري: قبل اليوم الأول

1. افتح صفحة الصندوق (tools/sandbox.html)، وحمّل «المختبر 1.1»، وتأكد أن تبويب «الصندوق» يعرض البريد والملفات.
2. اقرأ رسالة لميس m01 وقالب التقرير.
3. اكتب ثلاث مهام متكررة من عملك، متعددة الخطوات، تمس البريد أو الملفات أو التقويم:

| المهمة | كم مرة في الشهر | ما المواد التي تمسها | تصنيف المواد | أسوأ ما يحدث لو أخطأ منفّذها |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |

4. اختر واحدة مرشحة لمهمة الوكيل المتعقَّبة، واكتب سطرًا: لماذا هي، وما الذي لن تسلّمه للوكيل منها.

لا تكتب في هذا النموذج اسمًا حقيقيًا ولا رقمًا حقيقيًا ولا نصًا من وثيقة غير عامة.
